# 测试维度说明

Prompt 测试五类维度及边界类型参考。

## 五类核心维度

| 维度 | 验证什么 | 合格标准 | 不合格信号 |
|------|----------|----------|------------|
| 稳定性 | 同输入多次，核心字段不漂移 | 3 次运行核心项一致 | 有时有边界值有时没有 |
| 边界输入 | 极端/不完整场景 | 提示不足或合理拆分 | 极短需求乱编方案 |
| 错误输入 | 矛盾/异常参数 | 先质疑再生成 | 顺着错误硬写 |
| 多轮一致 | 规则延续 | 第二轮遵守第一轮 | 忘掉格式/覆盖项 |
| 幻觉风险 | 证据不足时克制 | 列证据清单 | 一行日志定根因 |

## 边界输入类型

| 类型 | 示例样本 | 期望行为 |
|------|----------|----------|
| 需求特别短 | samples/02 | 追问缺失信息 |
| 需求特别长 | samples/07 | 拆分模块、抓重点 |
| 字段信息缺失 | 只写「支持登录」 | 列出缺失项 |
| 业务规则模糊 | 「支付成功后处理订单」 | 追问具体规则 |
| 多需求混合 | samples/03 | 先拆模块 |
| 包含冲突信息 | samples/04 | 指出矛盾 |

## 错误输入类型

- 需求自相矛盾（samples/04）
- 参数异常（samples/06，如负数有效期）
- 字段缺失严重
- 日志内容无关
- SQL 语句不完整
- Bug 描述没有现象
- 接口文档缺少 URL 和参数
