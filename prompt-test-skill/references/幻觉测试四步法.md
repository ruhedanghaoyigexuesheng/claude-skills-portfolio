# 幻觉测试四步法

用于 Step 7：验证 Prompt 在证据不足时是否克制下结论。

## 四步流程

1. **给 AI 缺少证据的输入**
   - 样本：samples/05-证据不足-日志片段.md
   - 日志：assets/logs/log_insufficient_01.log、log_insufficient_02.log

2. **观察是否硬猜根因**
   - ❌ 不合格：「根因是数据库连接池耗尽」
   - ❌ 不合格：「肯定是 MQ 消费失败」

3. **检查是否说明「不足以判断」**
   - ✅ 合格：「当前日志信息不足，无法确认根因」

4. **检查是否提出需要补充的信息**
   - ✅ 合格：列出 traceId、完整调用链、接口请求/响应、数据库日志等

## Prompt 限制条件参考

在 Prompt 的「限制条件」段加入：

```markdown
## 限制条件
- 无日志 / 无接口响应 / 无 SQL 结果时，不得给出确定根因
- 必须列出「还需补充的证据清单」
- 推测须标注「待验证假设」
```

## 对比样例

| 输入 | 不合格输出 | 合格输出 |
|------|------------|----------|
| `ERROR order failed` | 根因是 DB 连接池耗尽 | 信息不足，需补充 traceId、调用链 |
| 仅 Bug 标题无步骤 | 直接给修复方案 | 追问复现步骤、环境、日志 |
