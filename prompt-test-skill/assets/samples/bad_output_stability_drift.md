# 稳定性漂移 — 劣质输出对比（3 次运行）

> 用于团队评审：展示同一 Prompt + 同一样本三次运行的不一致表现。

## 运行 1（相对完整）

| 用例编号 | 场景 | 风险等级 |
|----------|------|----------|
| TC-001 | 验证码正确登录成功 | P0 |
| TC-002 | 验证码错误 | P1 |
| TC-003 | 验证码过期（5 分钟） | P1 |
| TC-004 | 60 秒内重复发送拦截 | P1 |
| TC-005 | Token 生成与返回 | P0 |

## 运行 2（漏项）

| 用例编号 | 场景 | 风险等级 |
|----------|------|----------|
| TC-001 | 登录成功 | — |
| TC-002 | 登录失败 | — |
| TC-003 | 忘记密码 | — |

**问题**：无验证码过期、无频控、无 Token、无风险等级列。

## 运行 3（格式漂移）

登录成功场景：输入正确验证码，预期进入首页。

登录失败场景：输入错误验证码，预期提示错误。

**问题**：从表格变成段落；场景数减少；无边界值。

## 不合格信号汇总

- 第一次有边界值，第二次没有
- 第一次有风险等级，第二次没有
- 第一次表格输出，第二次变成段落
