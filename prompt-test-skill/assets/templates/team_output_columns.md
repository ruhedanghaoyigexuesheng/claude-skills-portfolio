# 团队输出模板 — 用例表列名清单

> 从团队 Excel 用例模板提取，用于判断 Prompt 输出「格式是否稳定」。

## 测试用例表（标准列）

| 列名 | 必填 | 说明 |
|------|------|------|
| 用例编号 | 是 | 如 TC-MODULE-001 |
| 模块 | 是 | 功能模块名 |
| 场景 | 是 | 一句话场景描述 |
| 前置条件 | 是 | 执行前状态 |
| 测试步骤 | 是 | 可执行步骤 |
| 预期结果 | 是 | 可验证结果 |
| 风险等级 | 是 | P0/P1/P2/P3 |
| 用例类型 | 否 | 功能/接口/安全 |
| 关联需求 | 否 | PRD 章节或需求 ID |
| 备注 | 否 | 历史 Bug 关联等 |

## Bug 分析报告（标准章节）

1. 输入摘要
2. 问题现象
3. 影响模块
4. 日志排查建议
5. SQL 排查建议
6. 历史 Bug 关联
7. 回归范围
8. 风险等级
9. 待验证假设
10. 人工复核清单

## 格式稳定性检查

Prompt 测试时，对比 3 次输出：

- [ ] 列名/章节名是否一致
- [ ] 表格 vs 段落是否一致
- [ ] 风险等级列是否始终存在
- [ ] 编号规则是否一致
