# 现象 → 模块映射表

按现象关键词匹配关联模块。可按实际业务扩展。

| 现象关键词 | 关联模块 |
|------------|----------|
| 支付成功、订单未更新 | 支付、订单、MQ、库存、优惠券 |
| 库存为 0 仍可下单 | 库存、订单、购物车、支付 |
| Token 失效、401 | 登录、网关鉴权、用户中心、权限 |
| 接口超时 | 网关、下游服务、DB 连接池、慢 SQL |
| 重复扣款 | 支付、订单、幂等、对账 |
| 优惠券未核销/未回退 | 优惠券、订单、支付、MQ |
| 退款失败 | 支付、订单、退款、对账 |
| 登录失败、验证码 | 登录、用户中心、短信网关、频控 |
| 消息未推送 | MQ、推送服务、用户中心 |
| 页面白屏、加载失败 | 前端、网关、CDN、后端 API |

## 支付域链路（参考）

```
用户下单 → 订单服务 → 支付服务 → 第三方渠道
                ↓           ↓
            库存扣减    支付回调 → MQ → 订单状态更新
                ↓                       ↓
            优惠券核销              库存确认 / 对账
```

## 使用说明

1. 从 Bug 描述中提取关键词
2. 匹配上表，列出所有关联模块
3. 按与现象的关联度标注 P0（直接）/ P1（间接）
