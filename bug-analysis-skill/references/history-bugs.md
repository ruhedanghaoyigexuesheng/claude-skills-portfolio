# 历史 Bug 库

每条包含：现象标签、模块、根因、修复方式、日志特征。持续沉淀，分析时按关键词 + 模块 + 日志特征匹配。

---

## BUG-2024-088

- **标签**：支付成功、订单未更新、MQ
- **模块**：支付、订单、MQ
- **根因**：MQ 消费失败，订单状态未更新
- **修复**：补偿任务 + 消费重试告警
- **日志特征**：`update order failed`, `mq consume error`

---

## BUG-2023-041

- **标签**：支付回调重复、幂等、重复扣款
- **模块**：支付、订单
- **根因**：支付回调重复到达，幂等校验未拦住
- **修复**：回调幂等键 + 分布式锁
- **日志特征**：`duplicate callback`, `idempotent check failed`

---

## BUG-2024-012

- **标签**：库存超卖、并发、锁
- **模块**：库存、订单、购物车
- **根因**：库存扣减未加分布式锁，并发下单超卖
- **修复**：Redis 分布式锁 + 乐观锁
- **日志特征**：`stock insufficient`, `oversell`, `lock timeout`

---

## BUG-2023-156

- **标签**：Token 失效、401、鉴权
- **模块**：登录、网关鉴权、用户中心
- **根因**：Token 刷新机制异常，旧 Token 未正确失效
- **修复**：双 Token 机制 + 网关统一鉴权拦截
- **日志特征**：`token expired`, `401 unauthorized`, `refresh failed`

---

## BUG-2024-055

- **标签**：接口超时、连接池、慢 SQL
- **模块**：网关、订单服务、DB
- **根因**：连接池耗尽 + 慢 SQL 导致下游超时
- **修复**：连接池扩容 + SQL 索引优化
- **日志特征**：`timeout`, `connection refused`, `pool exhausted`
