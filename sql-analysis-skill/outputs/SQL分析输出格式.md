# SQL 分析输出格式

## 必须按顺序输出 8 个小节

1. **SQL 风险识别** — 对照 sql_risk_signals.md 列出命中项
2. **where 条件分析** — 过滤范围、区分度、函数/隐式转换
3. **索引判断** — 建议验证的索引组合（不写死「必须加」）
4. **慢查询判断** — 扫描行数、返回字段、锁等待
5. **join 风险** — 无 join 写「不适用」
6. **order by 风险** — filesort、排序前数据量
7. **性能风险** — 类型 / 原因 / 影响 / 表现 / 验证方式 / 风险等级 P0–P2
8. **优化建议** — 至少 3 条，须含 explain 验证

## 第 7 节表格模板

| 字段 | 内容 |
|------|------|
| 风险类型 | |
| 风险原因 | |
| 影响范围 | |
| 可能表现 | |
| 验证方式 | |
| 风险等级 | P0 / P1 / P2 |

## 禁止

- 无依据断言「必须加索引 xxx」
- 跳过验证方式
- 跳过任一步骤
- 无风险等级

## 证据不足时附加

```markdown
## 待补充信息

- [ ] 表结构 / 索引定义
- [ ] 核心表数据量
- [ ] EXPLAIN 结果
- [ ] 慢查询日志片段
```
