# 证据不足 — 缺失信息清单

当 raw_log 少于 3 类有效信号（级别 / 服务 / 异常词 / traceId 等）时，**禁止输出根因**，仅输出本清单与补充采集建议。

## Checklist

- [ ] 缺少 traceId / requestId
- [ ] 缺少请求参数
- [ ] 缺少接口响应
- [ ] 缺少上下游服务日志
- [ ] 缺少发生时间范围
- [ ] 缺少环境信息（测试 / 预发 / 生产）
- [ ] 缺少版本变更说明

## 补充采集建议（模板）

| 缺失项 | 建议采集方式 |
|--------|--------------|
| traceId 全链路 | 按 traceId + 时间窗在 ELK/云日志检索各服务 |
| 请求参数 | 网关 access log 或业务 audit log（脱敏） |
| 下游响应 | 调用方 outbound log 或 APM span |
| 环境 / 版本 | 发布记录、配置中心变更单 |
