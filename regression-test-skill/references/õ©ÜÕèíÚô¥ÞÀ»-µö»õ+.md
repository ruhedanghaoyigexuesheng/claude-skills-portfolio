# 支付业务链路（回归补全用）

## 主链路

```
下单 → 创建订单 → 待支付
     → 发起支付 → 支付渠道
     → 支付回调 → 订单状态更新（已支付）
     → 库存扣减
     → 优惠券核销
     → 支付流水记录
```

## 异常与逆向链路

```
支付失败 → 订单保持待支付 → 库存预占释放（若适用）
订单取消（待支付）→ 库存释放 → 优惠券返还 → 支付入口失效
退款申请 → 退款回调 → 订单状态（已退款）→ 库存回滚 → 优惠券返还 → 支付流水
```

## MQ / 异步

```
支付成功 → MQ：订单已支付事件 → 库存服务 / 营销服务 / 通知服务
重复回调 → 幂等校验 → 禁止重复扣款 / 重复扣库存
```

## 回归补全结论

支付回调改动后，不能只测支付接口；还应回归：

- 订单状态同步
- 库存扣减与回滚
- 优惠券核销与返还
- 支付流水一致性
- 退款链路入口
- MQ 重复消费与幂等
