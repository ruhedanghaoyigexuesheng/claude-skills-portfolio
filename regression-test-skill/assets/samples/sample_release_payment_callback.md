# 版本改动说明 · 支付回调（A1 主案例输入）

> 脱敏示例，用于演示回归工作流主案例。

## 版本信息

- **版本号**：v2.8.3
- **类型**：Bug 修复 + 逻辑优化
- **计划发布**：2026-06-25

## 改动摘要

本次版本优化支付回调接口，修复支付成功后订单状态偶发未更新的问题。

## 详细说明

### 背景

线上偶发出现：用户支付成功，支付渠道已扣款，但订单仍显示「待支付」。根因初步定位为回调处理与订单状态更新之间存在竞态，且部分重试场景未正确幂等。

### 改动点

1. **支付回调接口** `/api/v1/payment/callback`
   - 优化回调处理顺序：先写支付流水，再更新订单状态
   - 增加基于 `payment_id` 的幂等校验
   - 修复高并发下订单状态更新丢失的问题

2. **订单状态服务**
   - 订单状态更新改为乐观锁 + 重试（最多 3 次）

### 影响范围（开发自评）

- 支付回调
- 订单状态更新
- 支付流水

### 未改动

- 支付下单接口
- 退款流程
- 前端支付页 UI
