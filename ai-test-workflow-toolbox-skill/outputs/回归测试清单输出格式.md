# 回归测试清单 · 输出格式

## 必须字段（表格或列表，字段名固定）

| 字段 | 说明 |
|------|------|
| 回归模块 | 被测模块名 |
| 回归场景 | 具体可执行场景描述 |
| 触发原因（本次改动） | 为何因本次改动需要测 |
| 关联历史 Bug | Bug ID 或「无」 |
| 风险等级 | P0/P1/P2/P3 |
| 执行优先级 | 必须/重点/可选 |
| 测试建议 | 查什么表/日志/接口 |

## 禁止

- 只列模块名不写场景
- 不说明触发原因
- 所有项同一优先级

## 输出模板

```markdown
## 改动摘要

- 直接改动：...
- 影响模块：...

## 回归测试清单

| 回归模块 | 回归场景 | 触发原因 | 关联历史Bug | 风险 | 优先级 | 测试建议 |
|----------|----------|----------|-------------|------|--------|----------|
| 订单状态 | 支付成功后状态为已支付 | 支付回调改动 | BUG-101 | P0 | 必须 | 查订单表、回调日志、流水 |
| ... | ... | ... | ... | ... | ... | ... |

## 人工复核清单

（复制 workflows/regression_testing.md 末尾 checklist，默认未勾选）
```

## 清单行示例

| 回归模块 | 回归场景 | 触发原因 | 关联历史Bug | 风险 | 优先级 | 测试建议 |
|----------|----------|----------|-------------|------|--------|----------|
| 订单状态 | 支付成功后状态为已支付 | 支付回调改动 | BUG-101 | P0 | 必须 | 查订单表、回调日志、流水 |
| 支付回调 | 同一 payment_id 重复回调仅处理一次 | 支付回调改动 | BUG-102 | P0 | 必须 | 模拟重复 POST 回调，查流水与订单 |
| 库存 | 支付失败/取消后预占释放 | 链路补全 | BUG-103 | P1 | 重点 | 查库存预占表、订单状态 |
| 优惠券 | 支付成功后核销；取消后返还 | 链路补全 | BUG-104 | P1 | 重点 | 查券状态、订单关联 |
| MQ | 重复消费不重复扣库存 | 链路补全 | BUG-105 | P1 | 重点 | 查消费日志、幂等键 |
| 支付流水 | 流水金额与订单一致 | 支付回调改动 | BUG-106 | P0 | 必须 | 对账表、回调 payload |
| 退款 | 退款后不可再次支付 | 链路补全 | BUG-107 | P1 | 重点 | 退款后调支付入口 |
