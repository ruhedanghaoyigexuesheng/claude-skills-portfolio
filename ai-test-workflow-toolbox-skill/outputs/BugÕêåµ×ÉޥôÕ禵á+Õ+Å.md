# Bug 分析输出格式

所有 Bug 分析助手输出 **必须** 按以下结构，字段不可省略：

```markdown
# Bug 分析报告

## 1. 输入摘要
## 2. 问题现象
## 3. 影响模块
## 4. 日志排查建议
| 优先级 | 服务/路径 | 关键词 | 关注点 |
## 5. SQL 排查建议
（可改参数的 SELECT，标注只读）
## 6. 历史 Bug 关联
## 7. 回归范围
- 必测（P0 链路）
- 建议测（关联模块）
- 抽测（低关联）
## 8. 风险等级
- **等级**：P0–P3
- **理由**：（1–2 句）
## 9. 待验证假设（若有）
## 10. 人工复核点
（引用 system/人工复核规则.md checklist）
```

完整样例：`examples/bug-analysis/payment-order-mismatch-report.md`
