# 登录模块 PRD（节选 · 边界测试用 · 超长输入）

> 本文件用于测试 Prompt 在超长 PRD 下的模块拆分与重点覆盖能力。完整版约 5000+ 字，此处保留核心章节结构。

## 1. 背景与目标

随着业务增长，现有账号体系需支持多种登录方式，并在安全、体验、合规之间取得平衡。本 PRD 描述登录模块 v2.0 的完整需求，涵盖手机号、邮箱、第三方 OAuth、企业 SSO 等入口。

## 2. 用户角色

| 角色 | 说明 |
|------|------|
| 普通用户 | C 端 App / H5 用户 |
| 企业用户 | B 端 SaaS 租户成员 |
| 管理员 | 后台运营人员 |
| 游客 | 未登录浏览用户 |

## 3. 功能需求

### 3.1 手机号验证码登录

- 支持 +86 手机号，11 位数字
- 验证码 6 位数字，有效期 5 分钟
- 同一手机号 60 秒内不可重复发送
- 同一 IP 每小时最多发送 20 次
- 验证码错误 5 次锁定 30 分钟
- 登录成功返回 JWT，有效期 7 天
- 支持 refresh token，有效期 30 天

### 3.2 邮箱密码登录

- 邮箱格式校验
- 密码 8–32 位，含大小写 + 数字
- 连续错误 5 次锁定 1 小时
- 支持忘记密码（邮件重置链接，24 小时有效）

### 3.3 第三方 OAuth

- 微信、支付宝、Apple ID
- 首次授权需绑定手机号
- 解绑需验证原手机号

### 3.4 企业 SSO

- SAML 2.0 / OIDC
- 租户隔离
- 登录态与 C 端独立

### 3.5 会话与安全

- 单设备登录 / 多设备登录（可配置）
- 异地登录短信提醒
- Token 黑名单（登出、改密后失效）
- 敏感操作二次验证

### 3.6 风控

- 设备指纹
- 异常 IP 拦截
- 人机验证（滑块 / 图形验证码）

## 4. 非功能需求

- 登录接口 P99 < 200ms
- 可用性 99.9%
- 日志保留 90 天
- 符合等保二级

## 5. 接口清单（节选）

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/v2/auth/sms/send | POST | 发送验证码 |
| /api/v2/auth/sms/login | POST | 验证码登录 |
| /api/v2/auth/email/login | POST | 邮箱登录 |
| /api/v2/auth/oauth/{provider} | GET | OAuth 跳转 |
| /api/v2/auth/token/refresh | POST | 刷新 Token |
| /api/v2/auth/logout | POST | 登出 |

## 6. 数据模型（节选）

- users：用户主表
- user_auth：认证方式绑定
- sms_log：验证码发送记录
- login_log：登录审计
- token_blacklist：Token 黑名单

## 7. 验收标准

- 所有 P0 场景用例通过
- 安全扫描无高危漏洞
- 压测 5000 QPS 无降级
