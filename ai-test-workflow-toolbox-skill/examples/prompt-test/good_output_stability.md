# 稳定性良好 — 优秀输出对比（3 次运行）

> 三次运行核心字段与结构保持一致（措辞可略有差异）。

| 检查项 | 运行1 | 运行2 | 运行3 |

| 验证码错误 | ✅ | ✅ | ✅ |
| 频控/重复发送 | ✅ | ✅ | ✅ |
| Token/会话 | ✅ | ✅ | ✅ |
| Markdown 表格 | ✅ | ✅ | ✅ |
| 风险等级列 | ✅ | ✅ | ✅ |

## 运行 1 示例（节选）

| 用例编号 | 模块 | 场景 | 预期结果 | 风险等级 |
|----------|------|------|----------|----------|
| TC-L-001 | 登录 | 验证码正确 | 登录成功，返回 Token | P0 |
| TC-L-002 | 登录 | 验证码过期（>5min） | 提示重新获取 | P1 |

## 合格标准

稳定性不要求每个字一样，而是要求 **核心字段、核心风险、输出结构** 稳定。
