# 登录模块 PRD 片段（正常样本配套）

> 用于稳定性测试与正常样本 01 的详细输入。可 @ 引用替代简短版 `examples/prompt-test/01-正常-登录需求.md`。

## 功能概述

用户通过手机号 + 验证码登录 C 端 App。

## 业务规则

| 规则项 | 说明 |
|--------|------|
| 手机号 | 11 位中国大陆手机号 |
| 验证码 | 6 位数字 |
| 有效期 | 5 分钟 |
| 发送频控 | 同一手机号 60 秒内不可重复发送 |
| 错误锁定 | 连续错误 5 次，锁定 30 分钟 |
| 登录成功 | 返回 JWT Token，有效期 7 天 |
| 未注册用户 | 提示「手机号未注册，请先注册」 |

## 接口

- `POST /api/v1/auth/sms/send` — 发送验证码
- `POST /api/v1/auth/sms/login` — 验证码登录

## 历史风险

- BUG-2024-0892：验证码频控曾失效，需重点覆盖
- BUG-2024-1023：Token 刷新后旧 Token 仍可用

## 验收关注点

- 验证码过期、错误、频控
- Token 生成与失效
- 未注册 / 已注销账号
