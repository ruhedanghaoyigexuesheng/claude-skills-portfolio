# 版本改动说明 · 订单取消（A2 课堂练习输入）

> 脱敏示例，用于课堂练习「订单取消逻辑改动」。

## 版本信息

- **版本号**：v2.9.0
- **类型**：功能优化
- **计划发布**：2026-07-02

## 改动摘要

本次版本修改了订单取消逻辑，支持用户在支付前主动取消订单。

## 详细说明

### 背景

此前待支付订单仅支持超时自动关闭，用户无法主动取消，导致库存长时间预占、优惠券无法释放。

### 改动点

1. **订单取消接口** `/api/v1/order/cancel`
   - 新增：待支付状态下用户可主动取消
   - 取消后释放库存预占
   - 取消后返还已锁定优惠券
   - 关闭该订单的支付入口

2. **订单状态机**
   - 新增状态流转：`待支付 → 已取消（用户主动）`

### 影响范围（开发自评）

- 订单取消
- 订单状态

### 未改动

- 已支付订单的取消/退款（仍走退款流程）
- 支付回调逻辑
