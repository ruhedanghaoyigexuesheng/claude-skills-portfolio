# 课堂练习 · 订单取消逻辑改动

## 8.1 题目

**输入改动**：

```text
本次版本修改了订单取消逻辑，支持用户在支付前主动取消订单。
```

完整版见 [`sample_release_order_cancel.md`](sample_release_order_cancel.md)。

## 8.2 要求交付

- 直接改动模块
- 影响模块
- 关联历史 Bug（可参考 [`../references/history-bugs-order.md`](../references/history-bugs-order.md)）
- 业务链路补全（参考 [`../references/业务链路-订单.md`](../references/业务链路-订单.md)）
- 风险等级
- 回归测试清单（≥6 行）
- 人工复核勾选结果

## 8.3 参考答案（要点）

```text
直接改动：订单取消
影响：订单状态、库存释放、优惠券返还、支付入口、购物车
历史：BUG-201 取消后库存未释放、BUG-202 取消后仍可支付、BUG-203 优惠券未返还
链路：下单→待支付→取消→库存释放→券返还→支付入口失效
P0：取消后仍可支付、订单状态；P1：库存、优惠券、重复取消、支付中取消并发
清单：取消成功、重复取消、取消后支付、库存恢复、券返还、状态流转
```

## 8.4 参考答案 · 清单骨架

| 回归模块 | 回归场景 | 触发原因 | 关联历史Bug | 风险 | 优先级 | 测试建议 |
|----------|----------|----------|-------------|------|--------|----------|
| 订单取消 | 待支付订单取消成功，状态为已取消 | 订单取消逻辑改动 | 无 | P0 | 必须 | 查订单表状态、操作日志 |
| 支付入口 | 取消后不可再发起支付 | 关闭支付入口 | BUG-202 | P0 | 必须 | 取消后调支付 API，应拒绝 |
| 库存 | 取消后预占库存释放 | 链路补全 | BUG-201 | P1 | 重点 | 查库存预占/可用量 |
| 优惠券 | 取消后锁定券返还可用 | 链路补全 | BUG-203 | P1 | 重点 | 查券状态、用户券列表 |
| 订单取消 | 重复取消幂等，友好提示 | 取消逻辑改动 | BUG-204 | P1 | 重点 | 连续两次 cancel |
| 订单状态 | 支付中与取消并发，最终状态一致 | 链路补全 | BUG-205 | P1 | 重点 | 并发 cancel + 支付回调 |
