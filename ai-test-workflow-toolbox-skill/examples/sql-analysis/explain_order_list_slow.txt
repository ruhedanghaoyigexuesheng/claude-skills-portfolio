
## 解读要点

| 列 | 值 | 含义 |
|----|-----|------|
| type | range | 使用 idx_status 范围扫描，非最优 |
| rows | 1750000 | 预估扫描约 175 万行（status=1 约占 35%） |
| Extra | Using filesort | 排序无法走索引，需额外排序 |
| key | idx_status | 仅用到 status 索引，未覆盖 order by |
