# 人工复核规则

以下结论 **必须由测试人勾选确认** 后方可作为正式结论：

- [ ] 根因是否有日志/SQL/接口证据
- [ ] 风险等级是否与业务影响一致
- [ ] 回归范围是否过大或过小
- [ ] SQL 优化建议是否需研发/DBA 确认
- [ ] 日志证据是否完整（含 traceId 链路）
- [ ] Prompt 测试样本是否覆盖边界与异常输入

## 使用方式

每份助手输出文末必须附「人工复核点」小节，引用本文件 checklist，默认全部未勾选，由测试人填写。

## 联动场景额外复核

多助手联动时（见 `workflows/联动工作流.md`），还需确认：

- [ ] 各助手结论是否相互一致（模块、风险等级）
- [ ] 是否按顺序执行，未跳步
- [ ] 联动案例是否包含 Bug + 日志 + SQL + 回归四类输出
