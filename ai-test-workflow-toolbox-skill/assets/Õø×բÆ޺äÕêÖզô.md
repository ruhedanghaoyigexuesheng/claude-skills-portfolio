| 改动类型 | 必回归模块 | 默认最高风险 |

| 订单状态机 | 订单、支付、库存、MQ 消费 | P0 |
| 库存扣减 | 库存、订单、购物车、并发下单 | P0 |
| 登录/鉴权 | 登录、网关、Token 刷新 | P1 |
| 列表查询/SQL | 对应接口、分页、排序、关联模块 | P1 |
| UI 文案/样式 | 对应页面展示 | P3 |
