# 日志规律库（工具箱汇总）

> **必须加载**。详细条目见 `references/log-analysis/log_pattern_history.md`。

## 关键词 → 排查方向（≥5 条）

| 日志特征 | 常见原因 | 建议先看 |
|----------|----------|----------|
| connection refused | 下游未启动、地址错误 | 服务健康检查、注册中心 |
| duplicate key | 重复提交、幂等失败、MQ 重复消费 | 订单号生成、消费位点 |
| lock wait timeout | 事务未释放、并发更新同一行 | 锁等待、事务日志 |
| Redis timeout | 连接池耗尽、Redis 阻塞 | Redis 监控、慢命令 |
| MQ consumer error | 消费逻辑异常、消息堆积 | 消费组 lag、死信队列 |
| update order status failed | 状态机冲突、回调重复 | 订单状态流转、支付回调幂等 |
| Read timed out | 下游慢、慢 SQL | 下游耗时、连接池 |

## 使用说明

- Bug 分析助手 Step 4 与日志排查助手 Step 5 均应引用本库
- 无匹配时输出：「无历史匹配，建议将本案入库」
