# Bug 输入标准模板

用户未按模板提供时，先追问缺失字段，再进入八步分析。

## 模板

```markdown
## Bug 标题
支付成功但订单状态仍显示未支付

## 环境信息
- 环境：生产 / 预发 / 测试
- 版本：App 3.2.1 / 服务端 build xxx
- 用户/订单 ID：（脱敏）

## 复现步骤
1. 提交订单 order_id=xxx
2. 微信支付成功
3. 返回订单详情页

## 实际结果
订单状态仍为「待支付」

## 预期结果
订单应显示「已支付」

## 接口信息（如有）
- 请求：POST /api/pay/callback ...
- 响应：{ "code": 0, "payStatus": "SUCCESS" }
- 错误码：

## 日志片段（如有）
粘贴相关 ERROR/WARN 行

## 附件
截图 / 录屏 / traceId
```

## 校验清单

| 字段 | 必填 | 缺失时追问 |
|------|------|------------|
| Bug 标题 | 是 | 请用一句话描述问题 |
| 环境信息 | 是 | 生产/预发/测试？版本号？ |
| 复现步骤 | 是 | 如何复现？ |
| 实际结果 | 是 | 实际看到什么？ |
| 预期结果 | 是 | 期望看到什么？ |
| 接口信息 | 否 | 有接口报错或 traceId 吗？ |
| 日志片段 | 否 | 有相关 ERROR/WARN 日志吗？ |

## 错误输入示例

```
订单有问题
```

此类输入无法分析，必须追问至至少具备：标题、环境、步骤、实际/预期结果。
