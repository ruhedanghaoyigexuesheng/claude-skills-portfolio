# 稳定性检查清单

对 `examples/prompt-test/01-正常-登录需求.md` 连续 3 次运行后，逐项对比 `records/01-正常-运行1~3.md`。

## 登录用例 Prompt 检查项

- [ ] 是否每次都有「验证码过期」相关用例
- [ ] 是否每次都有「验证码错误」相关用例
- [ ] 是否每次都有「频控 / 重复发送」相关用例
- [ ] 是否每次都有 Token / 会话相关用例
- [ ] 是否每次都按同样字段 / 表格格式输出
- [ ] 是否每次都有风险等级列
- [ ] 用例编号规则是否一致

## 记录方式

| 检查项 | 运行1 | 运行2 | 运行3 | 一致 |
|--------|-------|-------|-------|------|
| 验证码过期 | | | | ☐ |
| 验证码错误 | | | | ☐ |
| 频控 | | | | ☐ |
| Token | | | | ☐ |
| 表格格式 | | | | ☐ |

## 不稳定表现（写入报告）

- 第一次有边界值，第二次没有
- 第一次有风险等级，第二次没有
- 第一次表格输出，第二次变成段落

## 合格定义

稳定性 **不是** 要求每个字一样，而是要求 **核心字段、核心风险、输出结构** 稳定。

## 执行注意

- 每次运行 **新开对话**
- 输入组合固定：`@prompts/待测Prompt.md` + `@examples/prompt-test/01-正常-登录需求.md`
- 至少 3 次，建议保存完整原始输出
