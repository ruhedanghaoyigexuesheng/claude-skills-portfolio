# 模块影响映射

## 支付域

| 直接改动模块 | 常见影响模块 |
|--------------|----------------|
| 支付回调 | 订单状态、支付流水、MQ、库存、优惠券、退款 |
| 支付下单 | 订单创建、库存预占、优惠券锁定、支付入口 |
| 退款 | 订单状态、支付流水、库存回滚、优惠券返还、MQ |

## 订单域

| 直接改动模块 | 常见影响模块 |
|--------------|----------------|
| 订单取消 | 订单状态、库存释放、优惠券返还、支付入口、购物车 |
| 订单创建 | 库存预占、优惠券锁定、支付入口、价格计算 |
| 订单状态机 | 支付入口、库存、优惠券、物流、退款 |

## 鉴权域

| 直接改动模块 | 常见影响模块 |
|--------------|----------------|
| 登录 Token | 鉴权接口、会话、多端登录、权限 |
| 权限校验 | 菜单可见性、接口访问、数据范围 |

## 规则

- **直接改动** = 代码/配置实际修改点
- **影响模块** = 数据或状态会被波及的模块（含下游）
