# 回归风险规则

## 维度

- 是否影响资金 / 订单 / 库存 / 权限
- 是否核心链路 / 是否有线上事故史
- 是否高并发 / 异步 MQ

详细等级定义见 [`P0-P3-风险定义.md`](P0-P3-风险定义.md)。

## 默认映射（支付回调场景）

| 回归项 | 风险 | 优先级 |
|--------|------|--------|
| 支付回调幂等 | P0 | 必须执行 |
| 订单状态同步 | P0 | 必须执行 |
| 支付流水一致性 | P0 | 必须执行 |
| 库存回滚 | P1 | 重点执行 |
| 优惠券状态 | P1 | 重点执行 |
| MQ 重复消费 | P1 | 重点执行 |
| 退款链路 | P1 | 重点执行 |
| 页面文案展示 | P3 | 时间允许再测 |

## 默认映射（订单取消场景）

| 回归项 | 风险 | 优先级 |
|--------|------|--------|
| 取消后仍可支付 | P0 | 必须执行 |
| 订单状态流转 | P0 | 必须执行 |
| 库存释放 | P1 | 重点执行 |
| 优惠券返还 | P1 | 重点执行 |
| 重复取消幂等 | P1 | 重点执行 |
| 支付中与取消并发 | P1 | 重点执行 |
| 取消原因展示文案 | P3 | 时间允许再测 |

## 应用规则

1. 先按维度判断，再查上表默认映射
2. 若历史 Bug 为 P0 同类，该项不低于 P1
3. 与 [`release_scope.md`](../../examples/regression-test/release_scope.md) 中「不做项」冲突时，标注「已裁剪」并说明原因
